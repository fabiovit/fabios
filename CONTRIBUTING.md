# Contributing / Contribuire

## Italiano
Issue e pull request sono benvenute. Prima di proporre modifiche importanti, apri una issue per descrivere il problema o la funzione desiderata.

Le modifiche devono mantenere compatibilità con Home Assistant, superare HACS Action e Hassfest e non compromettere la compatibilità con i dati esistenti.

## English
Issues and pull requests are welcome. Before proposing major changes, open an issue describing the problem or requested feature.

Changes should remain compatible with Home Assistant, pass HACS Action and Hassfest, and preserve compatibility with existing user data.
